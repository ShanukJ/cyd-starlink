## Which board is this?

"ESP32-2432S028" (the *Cheap Yellow Display*, CYD) is sold with two different
display controllers on the same PCB and pinout:

| Variant | Controller | Commonly seen as |
|---|---|---|
| Original / "R" / "Rv2" | ILI9341 | single micro-USB |
| "Rv3" | **ST7789** | micro-USB + USB-C ("CYD2USB"), "7789" on the box |

The USB connector count is **not** a reliable indicator — some dual-USB
boards are ILI9341.

### Panel IDs are not a reliable identifier

The ST7789's RDID1/RDID3 registers are programmed by the *module vendor*.
The widely quoted `85 85 52` is only the ST7789 default. The first
verified unit (October 2026) reads:

| Register | Value |
|---|---|
| RDID1..3 (`DAh`..`DCh`) | `81 81 B3` |
| RDDID (`04h`, 1 dummy bit) | `81 81 81` |
| ILI9341 RDID4 (`D3h`) | `00 00 00` (an ILI9341 returns `..93 41`) |

LovyanGFX's autodetect expects RDDID byte 1 to be `0x85` (ST7789) or `0x00`
(ILI9341), so it would not detect this unit. The firmware therefore does not
gate anything on the panel ID. At boot it logs the module ID and verifies
the panel is alive by reading RDDPM (`0Ah`), which should be `0x9C`: booster
on, awake, normal mode, display on.

ST7789 8-bit register reads have **no** dummy clock. With LovyanGFX's default
of one dummy bit, every byte comes back shifted left by one.

## Pin mapping

Display and touch use **separate** SPI buses.

### Display — HSPI (SPI2), IOMUX pins

| Signal | GPIO | Notes |
|---|---|---|
| SCLK | 14 | |
| MOSI | 13 | |
| MISO | 12 | used only for register readback (health check) |
| CS | 15 | |
| DC | 2 | |
| RST | — | tied to the ESP32 EN line |
| Backlight | 21 | active high, PWM via LEDC |

| Signal | GPIO | Notes |

| CS | 33 | |
| IRQ (PENIRQ) | 36 | input-only, active low; not used for gating, shown on test screen |

## Sources

Pins were cross-checked across three independent sources (October 2026):

1. **LovyanGFX** autodetect, `_detector_Sunton_2432S028_7789_t` — identifies
   the ST7789 board by RDDID `0x85` and configures these exact pins.
2. **rzeldent/platformio-espressif32-sunton**, `esp32-2432S028Rv3.json` — ST7789
   board definition with the same display/touch/backlight pins.
3. **witnessmenow/ESP32-Cheap-Yellow-Display**, `PINS.md` — the original
   ILI9341 board. Same PCB pinout, so the pins agree.

## Verified on hardware

First unit: ESP32-D0WD-V3 rev 3.1, module ID `81 81 B3` (October 2026).

| Setting | Value | Result |
|---|---|---|
| Inversion | `invert = false` | dark background ✓ |
| Colour order | `bgr = true` | RED/GREEN/BLUE/WHITE bars correct ✓ |
| Orientation | `defaultRotation = 0` | portrait, upright, USB connectors at the bottom ✓ |
| Touch calibration | x 3900→300, y 200→3700 | crosshair under the finger in all four rotations ✓ |
| Backlight PWM | GPIO21, 12 kHz, 8 bit | dims smoothly ✓ |
| Touch IRQ | GPIO36 | reads LOW while pressed ✓ (wired, though unused) |
| MISO / readback | GPIO12 | driven by the panel (same reads with pull-up and pull-down) ✓ |
| SPI clock | 40 MHz write | no artefacts seen |

The two pin sources disagreed on colour order: LovyanGFX sets BGR,
rzeldent configures RGB. The hardware settles it: BGR is correct.
rzeldent's Rv3 definition also lists MISO as not connected, but on this unit
it is connected.
