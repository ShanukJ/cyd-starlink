STARLINK MONITOR

A standalone Starlink status display for ESP32 "Cheap Yellow Display" boards. Install it from this page, no software needed.

1. CHOOSE YOUR BOARD

The ESP32-2432S028 exists with two different display chips. Check yours before installing.

2. CONNECT AND INSTALL

  1. Use Chrome or Edge on a computer (Web Serial is not available in Safari, Firefox or on phones).
  2. Plug the board in with a USB data cable. On the dual-USB board use the micro-USB port.
  3. Click Connect, pick the serial port (often "USB Serial" / CH340), then choose Install. Choosing not to erase keeps your WiFi settings when updating.
This browser can't talk to USB devices. Use Chrome or Edge on a desktop computer. Web Serial needs a secure page (https:// or localhost).

If no port shows up, install the CH340 USB driver, or hold the BOOT button while the install starts.

3. FIRST SETUP

  1. The screen shows a WiFi network STARLINK-MONITOR-XXXX, a password and a QR code.
  2. Join it with your phone; the setup page opens (or browse to http://192.168.4.1).
  3. Pick the WiFi network that can reach your dish (usually the Starlink router's) and save.

Afterwards, settings are at http://starlink-monitor.local/.
